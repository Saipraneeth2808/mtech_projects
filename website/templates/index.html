Model Architectures

Four AI Models, One Pipeline

Each model handles a distinct aspect of cervical spine pathology analysis.

🧠

CNN Classifier

CONVOLUTIONAL NEURAL NETWORK

Multi-layer convolutional feature extraction for severity and pathology classification. Uses RBF kernel SVM proxy for sandbox compatibility.

Severity Accuracy 93.1%
🏗️

VGGNet

DEEP CONVOLUTIONAL NETWORK

VGG-16 inspired deep architecture with 13 convolutional layers and 3 fully connected layers. Excels at texture and structural feature extraction.

Problem Accuracy 96.6%
🔷

U-Net

ENCODER–DECODER SEGMENTATION

Skip-connection encoder–decoder for precise anatomical segmentation of vertebral bodies, discs, and spinal canal at each cervical level.

Regions Detected Per slice
🌀

VAE

VARIATIONAL AUTO-ENCODER

Learns the latent distribution of normal spinal anatomy. Reconstruction error serves as an anomaly score to flag unusual pathology.

Anomaly Detection 15.5% flagged
